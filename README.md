# Web-App-Midterm

Project for Web Programming & Applications – Topic 4: Containerization (Docker).

## Project Overview

A web application developed to demonstrate a containerized multi-service architecture using Docker Compose.

Planned services:
- Frontend
- Laravel Backend API
- MariaDB Database
- Redis Cache

## Project Status

Initial repository setup. Application source code and Docker configuration will be added in separate branches and integrated into `main` through pull requests.
